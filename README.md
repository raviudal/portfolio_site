# Algorithmic Trading & FinTech Portfolio

A modern, high-converting single-page portfolio tailored for **algorithmic trading engineers, quantitative software developers, and fintech specialists**.

Designed to be hosted with zero cost directly on **GitHub Pages**.

---

## 🚀 Live Preview & Deployment on GitHub Pages

### Option 1: Using your personal user site (`username.github.io`)
1. Create a repository named `<your-github-username>.github.io` on GitHub.
2. Push the files in this directory to `main`:
   ```bash
   git add .
   git commit -m "Launch quant portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-username>.github.io.git
   git push -u origin main
   ```
3. Your portfolio will immediately be live at `https://<your-username>.github.io/`

### Option 2: Using a project repo (e.g., `trading-portfolio`)
1. Push this folder to a GitHub repo named `trading-portfolio`.
2. Go to repository **Settings** &rarr; **Pages** &rarr; Source: **Deploy from a branch** &rarr; select `main` / `root` &rarr; Save.
3. Your site will be live at `https://<your-username>.github.io/trading-portfolio/`
